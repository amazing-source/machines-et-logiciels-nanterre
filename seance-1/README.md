## Pour vérifier tes valeurs

- Un bitmap 24 bits pèse `largeur × hauteur × 3 + 54` octets : tes deux bitmaps (l'étoile et l'image vide) font donc **la même taille**. C'est le résultat attendu.
- Le jpeg est bien plus petit que le bitmap ; le zip d'un bitmap est minuscule ; le zip d'un jpeg ou d'un png ne gagne presque rien.
- `recettefondant.odt` pèse 14 676 octets pour tout le monde ; le `.txt` fait moins de 1 000 octets.
