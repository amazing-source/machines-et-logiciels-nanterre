## Ce que contient le classeur

Neuf feuilles : les six exercices et trois tableaux croisés dynamiques. Les données sont fournies : tout le monde obtient les mêmes chiffres.

| Exercice | Contenu |
|---|---|
| 1 | tri sur deux niveaux, filtres, barres de données, icônes, règle `=$J5<0,15` qui surligne la ligne |
| 2 | liste déroulante, validation « entier de 1 à 5 », graphique en secteurs, histogramme |
| 3 | TCD Région × Catégorie avec filtre Vendeur ; TCD du nombre de commandes par vendeur |
| 4 | `NB.SI.ENS` = 3 ; `BDSOMME` = 93 110,00 € ; `BDMOYENNE` = 5 297,17 € ; filtre avancé : 12 lignes ; feuille protégée |
| 5 | mise en forme conditionnelle, ratio avec `SIERREUR`, ruptures à Paris = 0, TCD Entrepôt × Catégorie |
| 6 | deux validations, moyenne qui affiche « Absent », `BDMOYENNE` Informatique = 11,19, deux graphiques, feuille protégée |

Le 0 de l'exercice 5 est juste : aucune des 350 références n'a une quantité nulle.

## Pour le personnaliser

Le mot de passe de l'exercice 6, les couleurs des mises en forme conditionnelles, le style des tableaux croisés, les titres des graphiques, le texte des messages de validation.
